# C++ — Module Week 06

*This project has been created as part of the 42 curriculum by sbonneau.*

This folder contains the C++ exercises for Week 06 (`ex00` → `ex02`).

## Description

This module focuses on scalar conversion, serialization, and runtime type identification.

## Exercises

- `ex00` — scalar literal conversion.
- `ex01` — pointer serialization/deserialization.
- `ex02` — identify real derived type at runtime.

```bash
make
```
