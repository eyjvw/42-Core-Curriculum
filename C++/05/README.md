# C++ — Module Week 05

This folder contains the C++ exercises for Week 05 (`ex00` → `ex03`).

Description

This module introduces exceptions and robust class design around bureaucracy forms.

Exercises

- `ex00` — `Bureaucrat` and exception-safe grade constraints.
- `ex01` — `Form` signing workflow.
- `ex02` — concrete forms derived from `AForm`.
- `ex03` — `Intern` form factory.

Build

```bash
make
```

Makefiles are standardized with `mk/variables.mk`, `mk/colors.mk`, `mk/rules.mk`.
