# ex01 — ScavTrap Inheritance

*This project has been created as part of the 42 curriculum by sbonneau.*

## Description

Second exercise of Module 03: derive `ScavTrap` from `ClapTrap` and specialize
its behavior while reusing base functionality.

## What you practice

- Public inheritance and constructor chaining.
- Overriding/adjusting inherited behavior.
- Adding derived-only capabilities (`guardGate`).

## Files

- `includes/ClapTrap.hpp`, `includes/ScavTrap.hpp`
- `src/ClapTrap.cpp`, `src/ScavTrap.cpp`, `src/main.cpp`
- `Makefile` + `mk/` fragments

## Build & Run

```bash
make
./ScavTrap
```
