# ex03 — DiamondTrap Multiple Inheritance

*This project has been created as part of the 42 curriculum by sbonneau.*

## Description

Final exercise of Module 03: build `DiamondTrap` using multiple inheritance
(`ScavTrap` + `FragTrap`) and implement identity behavior.

## What you practice

- Multiple inheritance patterns in C++98.
- Name/state disambiguation (`ClapTrap::name` vs `DiamondTrap::name`).
- Reusing and combining behaviors from several base classes.

## Files

- `includes/ClapTrap.hpp`, `ScavTrap.hpp`, `FragTrap.hpp`, `DiamondTrap.hpp`
- `src/ClapTrap.cpp`, `ScavTrap.cpp`, `FragTrap.cpp`, `DiamondTrap.cpp`, `main.cpp`
- `Makefile` + `mk/` fragments

## Build & Run

```bash
make
./DiamondTrap
```
