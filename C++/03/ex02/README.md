# ex02 — FragTrap Specialization

*This project has been created as part of the 42 curriculum by sbonneau.*

## Description

Third exercise of Module 03: implement `FragTrap` as another derived class,
with its own stats and specialized action.

## What you practice

- Extending a class hierarchy with consistent semantics.
- Managing constructor/destructor messaging across inheritance.
- Adding extra derived method behavior (`highFivesGuys`).

## Files

- `includes/ClapTrap.hpp`, `includes/FragTrap.hpp`
- `src/ClapTrap.cpp`, `src/FragTrap.cpp`, `src/main.cpp`
- `Makefile` + `mk/` fragments

## Build & Run

```bash
make
./FragTrap
```
