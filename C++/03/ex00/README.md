# ex00 — ClapTrap Base Class

Description

First exercise of Module 03: implement the `ClapTrap` class with core state
and actions (attack, take damage, be repaired).

What you practice

- Basic class design with attributes and methods.
- Constructor/destructor behavior and state updates.
- Consistent output-driven testing from `main`.

Files

- `includes/ClapTrap.hpp`
- `src/ClapTrap.cpp`, `src/main.cpp`
- `Makefile` + `mk/` fragments

Build & Run

```bash
make
./ClapTrap
```
