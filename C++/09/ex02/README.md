# ex02 — PmergeMe

*This project has been created as part of the 42 curriculum by sbonneau.*

## Description

Implement and benchmark a hybrid merge-insert sorting strategy.

Containers: `std::vector` and `std::deque`, both sorted with the Ford-Johnson merge-insertion algorithm.

Input: positive integers up to `INT_MAX` (0 included). Negative numbers, non-numeric arguments, overflow, no argument and duplicate values are rejected with `Error` on stderr.

## Build & Run

```bash
make
./PmergeMe 3 5 9 7 4
```
