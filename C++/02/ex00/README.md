# ex00 — Fixed Point Basics

*This project has been created as part of the 42 curriculum by sbonneau.*

## Description

First step of Module 02: create the `Fixed` class and implement its canonical form
(constructor, copy constructor, assignment operator, destructor).

## What you practice

- Orthodox Canonical Form in C++98.
- Static class member usage (`_fractionalBits`).
- Basic getter/setter behavior for raw fixed-point storage.

## Files

- `includes/Fixed.hpp`
- `src/Fixed.cpp`, `src/main.cpp`
- `Makefile` + `mk/` fragments

## Build & Run

```bash
make
./Fixed
```
