# ex02 — Full Fixed Operators

*This project has been created as part of the 42 curriculum by sbonneau.*

## Description

Third step of Module 02: complete operator overloads for `Fixed`
(comparisons, arithmetic operations, increment/decrement, min/max).

## What you practice

- Overloading binary and unary operators.
- Implementing const/non-const overload pairs.
- Preserving precision and correctness in fixed-point operations.

## Files

- `includes/Fixed.hpp`
- `src/Fixed.cpp`, `src/main.cpp`
- `Makefile` + `mk/` fragments

## Build & Run

```bash
make
./Fixed
```
