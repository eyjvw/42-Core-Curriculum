# ex00 — megaphone

*This project has been created as part of the 42 curriculum by sbonneau.*

## Description

Simple exercise to manipulate command-line arguments and print transformed text to stdout.

## What you practice

- Parsing `argc` / `argv`.
- Iterating and transforming `std::string` characters (e.g. uppercase conversion).
- Handling empty input and printing usage-friendly messages.

## Files

- `megaphone.cpp`: main implementation.
- `Makefile` (includes `mk/` fragments) to build the `megaphone` binary.

## Build & Run

```bash
make
./megaphone "hello world"
```
