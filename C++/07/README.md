# C++ — Module Week 07

This folder contains the C++ exercises for Week 07 (`ex00` → `ex02`).

Description

This module introduces templates and generic programming patterns.

Exercises

- `ex00` — function templates.
- `ex01` — generic iteration utility.
- `ex02` — templated dynamic array.

Build

```bash
make
```

Makefiles are standardized with `mk/variables.mk`, `mk/colors.mk`, `mk/rules.mk`.
