# ex01 — Horde & Arrays of Objects

Description

Exercise focusing on creating multiple objects, managing an array (or horde) of instances,
and ensuring proper construction and destruction for each element.

What you practice

- Creating factories that allocate multiple objects.
- Correct destructor behavior for arrays of objects.
- Interface design for simple object collections.

Files

- `includes/` — headers for classes
- `src/` — implementation
- `Makefile` — build rules

Build & Run

```bash
make
./ZombieHorde
```

Notes

- Pay attention to memory leaks and ownership when using dynamic arrays.
