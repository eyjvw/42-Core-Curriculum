# C++ — Module Week 08

*This project has been created as part of the 42 curriculum by sbonneau.*

This folder contains the C++ exercises for Week 08 (`ex00` → `ex02`).

## Description

This module focuses on STL containers, algorithms, and adapter extension.

## Exercises

- `ex00` — search in containers.
- `ex01` — fixed-size number span calculations.
- `ex02` — iterable stack adapter.

## Build

```bash
make
```

Makefiles are standardized with `mk/variables.mk`, `mk/colors.mk`, `mk/rules.mk`.
